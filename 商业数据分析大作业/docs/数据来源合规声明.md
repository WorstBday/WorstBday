## 三、获取方式合规性

本项目严格采用课程要求的**白名单方式**获取数据：

1. **官方数据集接口直接下载**：通过 Kaggle 公开数据集下载接口一次性获取 ZIP 压缩包，未使用任何抓取技术。
2. 未使用 Scrapy、Selenium、requests + 网页解析、模拟登录、破解接口等任何爬虫手段；
   项目代码中不存在任何 HTTP 请求网页或解析 HTML 的逻辑（`download_data.py` 仅调用一次数据集下载接口）。
3. 未对数据源服务器造成额外负载：全程仅 1 次请求，文件大小 562,846 字节。

## 四、授权与使用范围

1. 该数据集为公开教学数据集，在 Kaggle 数据集页面以公开方式提供下载，适用于学习、研究与教学演示场景。
2. 本项目仅将数据用于课程作业的统计分析、建模与可视化展示，**不用于任何商业用途**，
   不再分发原始数据用于营利目的。
3. 项目仓库公开后，原始数据以 `data/raw/` 形式留档以支持复现；若后续权利人提出异议，可随时移除数据文件，
   仅保留数据获取脚本与分析代码。

1. 全部分析结果均由原始数据经上述脚本计算得到，**未人工修改任何数值**；
