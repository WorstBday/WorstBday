# 基于 Superstore 零售数据的客户价值分层与经营诊断分析

> 《商业数据分析》期末大作业 · 完整 Python 数据管道 + 24 张图表 + 交互式大屏 + 期末论文

本项目以 **Tableau Sample - Superstore** 公开零售订单数据为研究对象，覆盖 2014-01 至 2017-12、
9,993 条订单明细，完成「数据合规获取 → 清洗治理 → 商业模型分析 → 可视化复现 → 交互大屏 → 商业洞察」
的端到端分析流程。全部图表由 Python（Matplotlib / Seaborn）与 ECharts（由 Python 生成配置）产出，
**未使用 Power BI、Tableau、Fine BI 等任何 BI 软件，未使用爬虫**。

## 3. 环境与一键复现

```bash
# 1) 创建环境并安装依赖
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt

# 2) 一键复现（约 1~2 分钟）
python run_all.py
```

`run_all.py` 依次执行 `01_load → 02_clean → 03_analysis → 04_visuals → 05_dashboard`，
产物分别落在 `data/clean/`、`outputs/tables/`、`outputs/figures/`、`outputs/dashboard/`。
全流程随机种子固定（`02_clean.py` 的极值抽样、RFM 的 K-Means `random_state=42`、散点抽样 `random_state=42`），
重复运行结果一致。

> 说明：本机运行时依赖安装在项目内 `.pylibs/` 目录（脚本会自动加入 `sys.path`），
> 该目录不纳入版本库；标准环境请直接 `pip install -r requirements.txt`。

## 4. 分析模型（8 个）

| 编号 | 模型 | 关键设定 | 主要结论 |
| --- | --- | --- | --- |
| M1 | 趋势与同比/环比 | 月度 GMV、3 期移动平均 | 2017 年 GMV 同比 +20.4%，利润同比 +14.2%，增速差扩大 |
| M2 | 帕累托 / ABC | 客户累计贡献 70%/90% 分级 | 38.5% 客户贡献 70% 销售额；1,894 个产品中 15.0% 贡献 70% |
| M3 | RFM 八分类 | 三指标**中位数**切分（R≤76 天、F≥6 单、M≥$2,256） | 「重要价值客户」占 25.1% 人数、贡献 39.5% 销售额；四类重要客户合计 50.1% 人数、80.2% 销售额 |
| M4 | 同期群留存 | 首购季度分组、季度口径、右删失屏蔽 | T+1 平均留存 24.3%，T+4 回升至 25.6%，呈「休眠—唤醒」型复购 |
| M5 | 波士顿矩阵 | 份额 × 增速，中位数划分四象限 | 明星：Phones/Binders/Accessories/Copiers/Storage；瘦狗：Tables/Bookcases 拖累利润 |
| M6 | SARIMA 预测 | 回测选阶 `SARIMA(1,1,0)×(0,1,1,12)` | 回测 MAPE 16.8%、RMSE $17,284；与 Holt-Winters(15.6%) 相当 |
| M7 | 关联规则 Apriori | 订单内子品类购物篮，支持度 ≥0.8%，Lift ≥1.05 | 平均购物篮 1.83 个品类，跨品类关联弱（最高 Lift 1.15） |
| M8 | 客户价值漏斗 | 全部客户 → 复购 → 高频 → 高价值 | 793 → 781 → 598 → 199，末级转化仅 33.3% |

## 6. 交互式大屏

`outputs/dashboard/dashboard.html` —— 单文件自包含（约 2.0 MB，内联 ECharts 5.5.1），
**双击即可离线打开**，含 8 类联动组件：

1. 4 张 KPI 指标卡（GMV / 利润 / 订单量 / 客户数）
2. 月度销售额与利润趋势（折线 + 面积）
3. 品类销售结构（环形图，可点击联动）
4. 区域销售额（横向条形，可点击联动）
5. 折扣率 × 利润率散点
6. 州 Top10 销售额条形
7. 子品类经营明细表（Top10）
8. 年份 / 区域 / 品类 三个筛选器 + 重置

筛选器与图形点击双向联动：任一筛选变化时，KPI、5 张图与明细表同步重算。

## 7. 主要商业结论

1. **增长质量下滑**：2017 年 GMV 同比 +20.4%，但利润仅 +14.2%，利润率由 13.43% 降至 12.74%。
2. **折扣换量已越过临界点**：折扣率与利润率相关系数 −0.86；无折扣订单平均利润率 29.5%，
   折扣 ≥40% 的订单平均利润率 −77.4%、亏损订单占比 100%。
3. **客户价值高度集中但非极端帕累托**：38.5% 客户贡献 70% 销售额，四类「重要客户」占 50.1% 人数、80.2% 销售额。
4. **复购呈休眠唤醒型**：季度同期群 T+1 留存 24.3%，T+4 回升至 25.6%，说明唤醒式营销有效但缺乏自然留存。
5. **品类结构失衡**：Tables、Bookcases 两个负利润率子品类合计销售额 $322K，直接侵蚀利润。
